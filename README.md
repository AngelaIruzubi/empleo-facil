# empleo-facil

App web con IA que ayuda a personas con discapacidad intelectual a encontrar empleo privado, con todo en lectura fácil y con pictogramas.

> Nombre provisional. Proyecto de portfolio en construcción.

## Qué hace

1. Crea el perfil de la persona con una entrevista guiada en lectura fácil.
2. Genera un CV doble: versión ATS para empresas y versión en lectura fácil para la persona.
3. Busca ofertas y las filtra por empresas que contratan a personas con certificado de discapacidad.
4. Escribe cartas de presentación adaptadas a cada oferta.
5. Prepara la entrevista de trabajo.

## Stack

Java 21 · Spring Boot 4 · Spring AI 2 · PostgreSQL · React + TypeScript · MCP
